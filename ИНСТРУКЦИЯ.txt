ИНСТРУКЦИЯ — Python-бот Funnel (Supabase + Telegram)
=====================================================

Что нужно: Python 3.10+ и доступ в интернет.

1) ЗАПОЛНИТЬ bot/config.py
   - SUPABASE_URL        → Project URL из Supabase (Project Settings → API):
                            https://xxxxxxxx.supabase.co
   - SUPABASE_SERVICE_KEY → service_role (Secret) key оттуда же
   (анон-ключ тоже работает, но service_role правильнее для бота)

2) УСТАНОВИТЬ ЗАВИСИМОСТИ (один раз, в папке bot/):
       pip install -r requirements.txt

3) ЗАПУСТИТЬ:
       python main.py
   Бот работает, пока открыто окно. Чтобы работал постоянно — запустите
   на сервере или в фоне.

ПРОВЕРКА:
   - В Supabase (Table Editor) есть воронки с непустым токеном,
     data.cache не false, status не Archived — бот подхватит их
     в течение SYNC_INTERVAL_SECONDS (по умолчанию 20 сек).
   - Напишите боту в Телеграм /start — он ответит первым шагом воронки.
   - В таблице funnel_users появится строка с user_id и current_step.

ГДЕ ЧТО ЛЕЖИТ:
   config.py            — ключи и интервалы синхронизации
   supabase_client.py   — клиент Supabase (PostgREST)
   telegram_api.py      — обёртка Telegram Bot API
   storage.py           — кэши воронок/шагов/клавиатур/юзеров
   steps.py/handlers.py — логика шагов и обработка апдейтов
   functions.py         — системные сообщения и формулы
   main.py              — запуск (long polling)

ЕСЛИ БОТ НЕ ОТВЕЧАЕТ:
   - Проверьте ключи в config.py (без плейсхолдеров YOUR-...).
   - Посмотрите лог: ошибки Supabase/Telegram пишутся в консоль.
   - Воронка в статусе Archived или с выключенным cache не обслуживается.
